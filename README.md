# Exvius Offline (beta)

**Beta builds of Exvius Offline for testing before they reach the main app.**

**[Download the beta APK](https://github.com/Elvlin/exvius-offline-beta/releases/download/v0.1.37/exvius-offline-v0.1.37-beta.apk)**

[What changed in v0.1.37](release/notes-v0.1.37.md)

Every new version comes here first. Once it is tested and confirmed working, it is released in the main app at [Elvlin/exvius-offline](https://github.com/Elvlin/exvius-offline).

This is an unofficial fan project. It is not affiliated with Square Enix or gumi.

## Install

1. [Download the beta APK](https://github.com/Elvlin/exvius-offline-beta/releases/download/v0.1.37/exvius-offline-v0.1.37-beta.apk) from the [release page](https://github.com/Elvlin/exvius-offline-beta/releases/tag/v0.1.37).
2. Install it on an **Android 7.0 or newer phone with 64-bit ARM support**.
3. Open it with an internet connection. The app downloads its own copy of the game data, about **17.4 GB**. Allow about **21 GB of free space** for setup.

The beta is a separate app (`com.exvius.vision.elvlin`). It installs beside the main app, keeps its own storage and its own saves, and updates only from this page.

## Saves

- Both apps use the same save format. **Save management > Export save** in one app makes a file that **Import save** in the other app reads.
- [`save/exvius-beta-test-save.zip`](save/exvius-beta-test-save.zip) is a fresh test save with maxed gil, maxed summon tickets and maxed raid coins, so you can try everything. Import it with **Save management > Import save**.
